Types of Inheritance ---
1-  Single ( jiska maine code push kiya hai )
Animal -> Dog
2- Multilevel (child ka child)
Animal
   |
 Mammal
   |
  Dog
3- Multiple---
Multiple Inheritance (Ek Child, Kai Parents)Jab
 ek single Child class, 
ek se zyada Base (Parent) classes se properties aur 
methods inherit karti hai, toh use Multiple Inheritance 
kehte hain.Real-world Example: Ek bachha (Child), jisme 
uske Father aur Mother dono ki qualities aati hain.Structure:
 Class A + Class B -> Class C


4- Hierarchical ( like class car hai aur fir uske two child class petrolcar,deiselcar and electriccar)
eg -         Animal
             /    \
            Dog   Cat

2. Hierarchical Inheritance (Ek Parent, Kai Children)Hierarchical
 Inheritance iska thik ulta hai. Jab ek single Base (Parent) 
 class se kai saari Derived (Child) classes banti hain,
  toh use Hierarchical Inheritance kehte hain. 
  Yeh ek tree-like structure banata hai.Real-world Example:
   Ek Father, aur unke teen bacche. 
   Teeno bacchon ko Father ki property (jaise Surname) milegi,
    par teeno bacche aapas mein alag honge.Structure:
    Class A --->  Class B, Class C, Class D
